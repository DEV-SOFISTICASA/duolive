O chat do TikTok ainda não está ligado. Para ligar (uma vez só):
1. Instale o programa gratuito Node.js (site nodejs.org, botão verde).
2. Abra a pasta conector do DuoLive, clique na barra de endereço, digite cmd e aperte Enter.
3. Na janela preta, digite npm install e aperte Enter (só na primeira vez).
4. Depois digite npm start -- @seuusuario (o @ da conta TikTok que vai fazer a live).
Pronto — quando a live começar, as mensagens aparecem aqui sozinhas.
Para ver como fica sem estar ao vivo: digite set DUOLIVE_TESTE=1, Enter, e depois npm start.
